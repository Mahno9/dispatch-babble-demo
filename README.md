# Babble demo

Демо бубнежа персонажей DispatchOleg: осциллятор на букву и сэмплы «как в Aurelia», пресеты на персонажа.
Страница: index.html (собирается `node build.mjs` из page.html, проверка `node check.mjs`).

Одиннадцать карточек: Олег (игрок) и 53…62. Пресеты 54, 57 и 58 отобраны разработчиком на слух,
остальные — прикидка по `voiceNote` из `artifacts/voices-20260905/casting.json`, их и надо слушать.
Свои «мх» есть только у 58 и 54; остальные играют банк Чейза со сдвинутым питчем, так и подписано.

Раскладка адаптивная и прокручивается по вертикали на любой ширине: до 720 px — одна колонка,
тач-цели 44×44 px, подвал свёрнут в «как это устроено»; 720–1100 px — две колонки; шире — три.
Поле текста в шапке липкое. Карточка сворачивается кнопкой «–» в строку «портрет · имя · ▶ ·
источник · сводка пресета»; кнопки «свернуть все» / «развернуть все» — в шапке, состояние живёт
в localStorage вместе с пресетами.

`node check.mjs` гоняет 39 проверок на 1440×900, 390×844, 360×740 и на промежуточных ширинах,
пишет screenshot.png (страница целиком) и screenshot-mobile.png.
