# Babble demo

Демо бубнежа персонажей DispatchOleg: осциллятор на букву и сэмплы «как в Aurelia», пресеты на персонажа.
Страница: index.html (собирается `node build.mjs` из page.html, проверка `node check.mjs`).

Раскладка адаптивная: до 720 px — одна колонка с прокруткой, тач-цели 44×44 px, подвал свёрнут
в «как это устроено»; 720–1100 px — две колонки; шире 1100 px — прежний вид на один экран без прокрутки.
`node check.mjs` гоняет проверки на 1440×900, 390×844 и 360×740 и пишет screenshot.png и screenshot-mobile.png.
